# College Enquiry Chatbot

A web-based chatbot that answers queries related to college details—such as admission procedures, course information, fee structures, department details, and campus facilities—using deep learning and natural language processing to provide real-time responses via a friendly GUI interface.

---

## 🧠 Features

- **Intent-based response**: Classifies student queries and provides appropriate answers.
- **Deep Learning-based NLP**: Trained using Bi‑LSTM (or RNN/LSTM) with pre‑trained embeddings for understanding context.
- **Graphical User Interface (GUI)**: Intuitive interface that mimics a natural chat experience, optionally including voice (text-to-speech) responses.
- **Suggestion box**: Collects user feedback to refine the system.
- **24×7 availability**: Always available, reducing administrative workload.

---

## 🏗️ Tech Stack

- **Backend**: Python (Flask or Django), NLP pipeline with deep learning (Keras, TensorFlow, or PyTorch)
- **Model**: Bi‑LSTM classifier trained on labeled intents/patterns/responses
- **Embeddings**: Pre‑trained embeddings like GloVe
- **Frontend**: HTML, CSS, JavaScript
- **Database**: JSON or SQLite for intents and logs
